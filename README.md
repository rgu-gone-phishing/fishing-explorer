# Fishing Explorer

Exploratory design for a reproducible, offline research tool built on Global Fishing Watch (GFW) data.

Start with the [API feasibility study and extraction playbook](docs/gfw-api-feasibility.md). It compares GFW's existing map with useful downstream research work, selects data sources, and records small authenticated API probes made with curl.

No application or downloaded dataset is present yet. `api-secret.txt` is a local credential and is ignored by Git.
